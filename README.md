### 🚀 Featured Projects

#### 🦴 Pediatric Wrist Bone Fracture Detection
A comprehensive deep learning pipeline for automated wrist fracture detection from X-ray images, developed as an M.Sc. thesis project. 
* **Dataset:** GRAZPEDWRI-DX dataset (High-resolution, medical-specific augmentations).
* **Architecture:** YOLOv11s (Small), trained for 60 epochs (40 initial + 20 extended) for enhanced feature extraction of subtle hairline fractures.
* **Key Features:** Conducted Confidence Threshold Sensitivity Analysis and implemented Test-Time Augmentation (TTA) to maximize detection robustness. Automated the generation of Confusion Matrices and ROC curves for clinical evaluation against baseline research.
* **🔧 Stack:** `Python` `PyTorch` `YOLOv11` `OpenCV` `NumPy`

#### 🚌 Farook College Bus Management System
A mobile-based application designed to streamline transit tracking, scheduling, and management for students and administrators.
* **Features:** Real-time live bus tracking, dynamic schedule management, secure role-based user authentication, and push notifications for delays or route changes.
* **Admin Tools:** Comprehensive backend panel for administrators to efficiently manage fleets, routes, and user access.
* **🔧 Stack:** `Flutter` `Dart` `Firebase` `Firestore`
